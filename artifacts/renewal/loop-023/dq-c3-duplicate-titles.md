## HG-004(a)에 영향을 주는 관찰

1. **19그룹 전부 병합 대상.** "동명이의라 유지" 예외를 만들 필요가 없다 —
   결정은 "병합할 것인가"만 남는다. 38건 중 19건이 사라지고 19개 slug에
   영구 리다이렉트가 필요하다(LOOP.md 절대규칙 7).
2. **자동 승자 선정이 안 통한다.** 근거·콘텐츠가 많은 쪽과 산문이 긴 쪽이
   서로 다른 그룹이 5건 있다(#10 펭수, #13 원영적 사고, #6 떡상, #19 혼밥,
   #4 차도남). 단순히 "src 많은 쪽 유지"로 하면 더 긴 설명을 버린다.
   → 문서 단위 승자 선택이 아니라 **필드 단위 병합**이 필요하다. 추천안 C
   (수동 확정)를 뒷받침한다.
3. **연도가 갈리는 그룹 6건**(#4, #5, #9, #10, #15, #16). 병합은 어느 쪽
   `origin_year`를 남길지 사실 확인을 요구한다. #9·#10은 상대 문서 본문이
   답을 이미 갖고 있고, #15는 명백한 오류(1집을 3집이라 서술)다.
   즉 병합 작업이 **기존에 몰랐던 사실 오류를 최소 1건 드러낸다.**
4. **DQ-C4와 겹친다.** #17은 한쪽 alias가 다른 쪽 정식 제목과 정확히
   일치해 alias 충돌 275건에도 포함된다. (a)와 (b)를 따로 처리하면
   같은 행을 두 번 만진다.
5. **태그는 38건 전부 0건.** (c) 태그 backfill을 (a) 병합보다 먼저 하면
   병합 시 태그도 다시 정리해야 한다 — (a) → (c) 순서가 낫다.

## 검증 한계

- 판정 근거는 **제목·요약·description·origin 텍스트뿐**이다. `meme_contents`의
  실제 영상이 같은 것을 가리키는지는 URL 대조를 하지 않았다.
- 정규화가 구두점만 제거하므로 **띄어쓰기·구두점이 아닌 표기 차이**로 갈린
  중복(예: "짜장면이 싫다고 하셨어" 단독 문서)은 이 19그룹에 잡히지 않는다.
  실제 중복 총량은 38건보다 클 수 있다.
