Core workflow

One application, three repeatable jobs

The paid product provides access to software features. Every feature is used online through a signed-in account.

01 / MONITOR

Saved watchlists

Save relevant records and see which ones changed, which signals are new, and which items need another review.

02 / VERIFY

Evidence workflow

Keep source notes, editorial status, safety context, and revision history together instead of rebuilding the same research each time.

03 / LOCALIZE

Language review queue

Request a supported locale, track its review state, and reopen the finished localized record from a single queue.
