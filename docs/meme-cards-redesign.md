# 밈카드 디자인·긁기 개선

## 경험

- 탐색 목록은 모든 카드에 같은 은색 홀로그램 뒷면을 보여준다. 이름·설명·카테고리·번호·밈 링크·아트는 공개 전 목록에 넣지 않는다.
- 원하는 밀봉 카드를 선택하고 실제로 긁기 시작하면 해당 카드의 현재 공개 가능 여부와 내용을 한 번 조회한다. 마우스 올리기·선택만으로는 내용 조회를 요청하지 않는다.
- 포인터를 따라 움직이는 반사광·브러시, 실제 코팅 제거, 코팅 조각, 작은 기울기와 공개 전환을 제공한다. 고유하게 지워진 면적 35%에서 공개하며, 진행률은 그 지점까지 0–100%로 표시한다.
- 키보드 사용자는 바로 공개 버튼을 이용한다. 캔버스 미지원·스크립트 초기화 전에도 뒷면은 불투명하다. 동작 줄이기 설정에서는 기울기·입자·전환을 줄인다.
- 공개된 앞면은 그래파이트 바탕, 밝은 글자, 절제한 색상과 선을 사용한다. 기존 1,000종의 의미·구성·카탈로그 번호는 유지한다.
- 카드 뒤섞기는 현재 페이지의 밀봉 카드 순서만 변경한다. 확률·희귀도·유료 추첨·추첨 기록은 추가하지 않는다.

## 데이터·경계

탐색 페이지의 클라이언트/RSC 카드는 `{id}`와 페이지 정보만 받는다. 기존 이름·카테고리 URL 필터는 탐색 페이지에서 무시하며 내 컬렉션의 검색은 유지한다. 첫 긁기 또는 접근성 공개 요청에 `GET /api/meme-cards/[id]`를 호출한다. 응답은 현재 공개 자격을 다시 확인하고 `no-store`를 사용한다. 잘못된 ID·공개 불가·저장소 오류는 각각 제한된 400·404·503 응답으로 처리한다. 서버 내부 예외는 노출하지 않는다.

응답은 동일 카드 ID·번호·아트 형태·내부 밈 URL을 검증한다. 중복 조회, 응답 본문 지연, 선택 취소, 다른 카드 선택, 재밀봉, 화면 종료에 대한 abort/세대 검사를 적용한다. 충분히 긁었어도 내용 조회가 실패하면 공개 성공으로 표시하지 않으며 같은 선택에서 재시도할 수 있다.

`revealed=1`은 이미 공개한 카드로 돌아오는 화면 상태이며 비밀 증명이나 소유권 증명이 아니다. 공개 카탈로그 API와 밈 자료는 공개 자료로 유지한다. 이 개선은 일반 탐색 화면과 그 초기 응답에서 정답을 숨기는 경험을 제공하며, 공개 API를 탐색하는 사용자에 대한 암호학적 비밀을 제공하지 않는다.

보유하기는 기존 로그인·서버 인증·RLS·명시적 클릭·멱등 저장 경계를 그대로 사용한다. 로그인 복귀는 같은 카드와 페이지를 유지하며 자동 보유하지 않는다. 데이터베이스 스키마·운영 카탈로그·밈 원문·임베딩·모델 설정·요금제·서비스 토큰은 변경하지 않는다.

## 검증

SSR/RSC 정보 숨김, 최초 조회 및 중복 방지, 오류·취소·늦은 응답·재밀봉, 실제 면적·리사이즈·포인터 취소, 키보드·미지원 캔버스·동작 줄이기, 기존 로그인·소유권 변경·보유 요청 회귀를 자동 검사한다. 최종 실행 결과·로컬 및 운영 브라우저 화면·배포 커밋 증거는 `.local/meme-cards-redesign-20261007/release.html`에 기록한다. 실제 운영 계정으로 보유를 추가하는 검사는 수행하지 않는다.

로컬 검증: 전체 396개 파일의 3,391개 테스트 통과, 타입 검사 통과, lint 오류 0개(기존 경고 6개), 단일 작업 빌드 110개 정적 경로 통과. 실제 게스트 브라우저 356개 검사, 별도로 모의 GET·캔버스 제어 86개 검사, 요청·오류 경계 4개 검사까지 총 446개 통과. 읽기 전용 HTTP·SSR/RSC 검사 13개 통과. 실제 운영 계정으로 보유를 저장하거나 모델·색인·운영 작업을 호출하지 않았다.

브라우저 검증에서 실제 PPAP 주소의 괄호를 거부하던 내부 URL 검증과 중앙 장식이 코팅 입력을 가로막던 레이어 순서를 수정했다. CSP를 유지하고 검증 도구의 문자열 eval 대기를 직접 평가 폴링으로 바꿨다. 실패한 최초 증거는 최종 성공 결과와 분리해 보관한다.
