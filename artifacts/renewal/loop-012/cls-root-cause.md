# PERF-002 — 상세 route CLS 원인 규명 (루프 012)

## 결론: 독립적으로 고칠 수 있는 항목이 아니다 → HG-005 대기

DevTools `CLSCulprits` 인사이트가 지목한 유일한 원인:

```
An unsized image (IMG)
url: https://img1a.coupangcdn.com/image/mobile/ajax-loader.gif
```

크기가 지정되지 않은 **쿠팡 제휴 광고 이미지**다. 즉 `PERF-002`(CLS)와
`DES-004`(제휴 도크가 본문을 덮음)는 **같은 요소가 원인**이고, 광고 배치 변경은
LOOP.md가 `HUMAN_GATE`로 규정한 항목이다(HG-005).

## 측정값이 실행마다 달라진다

| 실행 | 조건 | CLS |
| --- | --- | ---: |
| 루프 009 | 콜드 캐시 | **0.12** |
| 루프 012 (1회차) | 웜 캐시 | **0.00** |

광고 이미지가 캐시돼 있으면 늦게 들어오지 않아 이동이 생기지 않는다. 루프 009의
0.12는 콜드 캐시 측정이었다.

**따라서 루프 009의 "상세 CLS 0.12" 기준선은 단일 측정값으로 다루면 안 된다.**
앞으로 CLS는 콜드 캐시 기준 최악값으로, 여러 회 측정해 기록해야 한다.

주의: 위 culprit 분석은 웜 실행(클러스터 점수 0.0000)에서 얻었다. 그 실행에서는
이동이 사실상 없었지만, 지목된 원인(크기 미지정 서드파티 광고 이미지)은 콜드
실행에서 0.12가 나온 양상과 일치한다.

## 정정된 완료 조건

`PERF-002`는 `HG-005` 결정에 종속된다. 선택지 C(도크 고정 유지 + 본문 하단 패딩
확보)를 택하더라도 **광고 이미지 자체에 크기를 예약**해야 CLS가 잡힌다. 서드파티
스크립트가 삽입하는 이미지라 컨테이너에 `min-height`를 고정하는 방식이 현실적이다.
