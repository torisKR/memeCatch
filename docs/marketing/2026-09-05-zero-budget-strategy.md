## 1. 누구에게 무엇을 알릴 것인가

- **우선 대상:** 한국어로 SNS 콘텐츠를 만드는 1인 크리에이터·브랜드 운영자. ‘뜻은 아는데 내 글에 써도 되는지 모르겠다’는 사용 상황을 다룬다.
- **보조 대상:** 한국 인터넷 표현을 이해하려는 해외 독자. 영어 소재는 계정의 기존 독자층과 실제 번역 페이지를 확인한 뒤 소규모로 시험한다.
- **한 문장 소개:** ‘밈의 뜻과 유래, 사용 맥락을 찾아보는 밈 사전, 밈캐치.’
- **첫 행동:** 회원가입이나 구매보다 상세 페이지 1개 읽기. 관심이 생긴 독자가 검색·출처 확인·다른 밈 탐색으로 이어지게 한다.
- **판단 근거:** 기존 [성장 기획서](../catchmeme_10usdt_growth_plan.html)는 콘텐츠 실무자를 1순위로 둔다. 과거 글로벌 전환 문서도 있지만 이번에는 0원으로 운영 가능한 한국어 연재를 우선 실험한다. 고객 인터뷰·키워드 검색량·채널별 전환율은 확보되지 않았으므로 타깃과 성과 기대는 검증할 가설이다.

## 7. 측정과 다음 결정

동봉한 [게시·성과 기록표](2026-09-05-campaign.csv)를 사용한다. 유료 단축 URL·분석 서비스를 새로 쓰지 않는다. [실행·HTTP 검증 기록](2026-09-05-evidence.json)에는 실제 확인 시각과 각 URL의 응답을 남겼다.

- 모든 링크: `utm_source=threads`, `utm_medium=social`, `utm_campaign=zero_budget_202609`, 글별 `utm_content`.
- P01의 게시된 링크는 Threads 리다이렉트로 감싸져 있지만 도착 URL에 위 UTM 네 값이 모두 보존됐다. 사전 점검의 스냅샷 URL 표현에서 일부 값이 빠졌으나 실제 탭 URL과 게시 링크에는 남아 있었다. 이 관찰만으로 실제 브라우저의 추적 값 제거를 확정하지 않는다. GA4 수집 여부는 별개다.
- 게시 직후: 계정·본문·공개 URL·게시 시각 기록. 성공 알림만 보지 말고 해당 글을 다시 열어 확인한다.
- 24시간/72시간: 노출 또는 조회, 링크 방문, 내용 있는 답변을 기록한다. 지표가 화면에 없거나 접근하지 못하면 빈칸으로 두고 이유를 쓴다. 미측정을 0으로 기록하지 않는다.
- 웹: GA4가 실제 수집 중일 때 캠페인별 세션과 `meme_view`, `search_submit`, `meme_source_opened`, `share_click` 등을 확인한다. 검색·상세로 이어진 방문을 보고, 이벤트 수를 사람 수로 오인하지 않는다.
- 현재 HTML 검사에서는 GA 스크립트 선언이 확인되지 않았다. 동적 로드 가능성까지 검증하지 않았으므로 ‘GA4 미설정’으로 단정하지 않지만, 수집이 된다고 가정해서도 안 된다. 첫 게시 후 Threads의 제공 지표를 우선 기록하고 웹 수집은 별도 확인한다.
- 활성화율을 계산하려면 세션 단위로 중복 제거한 분모·분자가 필요하다. 현재는 계산 가능 여부를 검증하지 않았으므로 임의 비율을 만들지 않는다.
- Threads는 게시물·프로필 링크 방문을 확인하는 기능을 안내하고 있다. 실제 계정에서 제공되는 지표와 GA4 세션은 정의가 달라 서로 일치하지 않을 수 있다. [Meta 링크·Insights 안내](https://about.fb.com/news/2025/03/new-threads-features-more-personalized-experience-you-control/amp/)

**첫 2주의 운영 목표:** 6개 글 게시, 6개 랜딩 확인, 반복해서 나타난 사용자 문제 3개 확보. 방문·가입·매출 목표치는 기준값이 없어 약속하지 않는다.

**계속할 기준:** 같은 콘텐츠 축의 글이 2개 이상 쌓이면 24시간 링크 방문과 의미 있는 답변을 비교한다. 조회만 높은 글보다 사전 이용을 만든 소재를 다음 주에 재사용한다. 표본이 적으면 결론을 보류한다.

**바꿀 기준:** 조회가 있는데 클릭이 없으면 다음 글의 도입·상세 링크 위치 중 하나만 바꾼다. 방문은 있는데 설명이 어렵다는 피드백이 반복되면 해당 문서 개선을 먼저 한다. 영어 글은 영어 독자·도착 페이지 품질이 확인될 때 늘린다. 결제 성과는 실제 결제 완료 증거가 있을 때 별도로 평가한다.

## 9. 현재 발견한 개선 후보

- 브금·잘자 내꿈꿔 상세는 상황별 검수 미완료를 표시한다. ‘회사·브랜드에서도 안심하고 사용’ 같은 광고 문구는 현재 근거가 부족하다.
- 영어 홈에는 한국 밖에서 시작된 밈도 섞여 있다. 해외 독자 캠페인은 실제로 소개할 한국어 표현의 영어 상세를 골라 연결하는 편이 명확하다.
- 기존 GeekNews 독자의 ‘밤티’ 누락 의견이 보였고, 현재 공개 검색에는 해당 문서가 나온다. 검색 누락·헷갈리는 설명 같은 구체적인 문제를 수집하는 데 커뮤니티를 활용한다. 이번에 댓글을 새로 작성하거나 기존 답변을 수정하지 않았다.

이 개선 후보는 제품·DB 변경 완료를 뜻하지 않는다. 이번 작업은 마케팅 전략 준비와 첫 홍보글 게시이며 애플리케이션 배포는 하지 않았다.
