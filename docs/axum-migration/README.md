# Next.js → Axum migration (history)

The site's Next.js app was replaced by the Rust server in `server/`, route by
route, between 2026-11-23 and the L1 batch that deleted the Next app. These
files are the record of that work: `PLAN.md` (decisions, the differences from
the old app kept on purpose, each batch's checks), `UI-PLAN.md` (the page
layer) and `inventory/` (what the Next app did, as found before the port).
Paths, commands and switches in them are those of that time.
