# SNS에 밈을 쓰기 전 확인할 5가지

밈캐치를 운영하며 정리한 무료 확인표입니다. 쓰려는 표현 하나에 적용해 보고, 아래 빈칸을 복사해 사용해 보세요.

## 게시 전 확인표

1. **뜻을 내 말로 설명할 수 있나요?** 한 문장으로 적어 보세요. 설명이 어렵다면 먼저 뜻을 찾아봅니다.
2. **상대와의 관계에 맞나요?** 친구에게 하는 말과 처음 보는 고객에게 하는 말을 구분합니다.
3. **농담이 빠져도 전달할 내용이 남나요?** 독자가 밈을 몰라도 알 수 있는 기본 문장을 적습니다.
4. **유래와 사용 맥락의 근거를 확인했나요?** 설명의 출처와 확인 중인 항목을 함께 봅니다.
5. **사용할 이미지·영상의 이용 조건도 확인했나요?** 표현의 의미를 아는 것과 해당 자료의 사용 허락은 별도로 확인합니다.

## 복사해서 쓰는 빈칸

쓰려는 표현:

읽을 사람 / 게시 위치:

전달하려는 내용:

뜻을 내 말로 한 문장:

밈을 몰라도 이해할 기본 문장:

확인한 출처 / 확인일 / 아직 모르는 부분:

## 예시 1. ‘브금’을 모르는 독자도 이해하도록

- 상황: 영상 편집을 처음 배우는 사람에게 음악을 고르는 방법을 안내하는 글.
- 처음 문장: “이 영상 브금은 어떻게 고르죠?”
- 맥락을 보완한 문장: “이 영상에 깔 배경음악(BGM)은 어떻게 고르죠?”
- 확인한 점: ‘브금’은 배경음악을 가리키는 표현입니다. 초보 독자에게는 풀어 적으면 질문의 뜻이 더 분명해집니다.
- [브금 설명 보기](https://catchmeme.com/memes/3fajbwre)

## 예시 2. 친한 사이의 인사와 고객에게 하는 인사

- 상황: 브랜드 계정에서 하루를 마무리하는 인사.
- 처음 문장: “잘자, 내꿈꿔.”
- 기본 문장으로 바꾼 예: “오늘도 수고 많으셨어요. 편안한 밤 보내세요.”
- 확인한 점: ‘잘자 내꿈꿔’의 친근한 분위기가 모든 독자와의 관계에 맞는지 먼저 봅니다. 이 예시는 밈을 빼도 인사의 목적이 남도록 직접 작성한 문장입니다.
- [잘자 내꿈꿔 설명 보기](https://catchmeme.com/memes/r2fg5gqv)

두 예시는 확인표 사용법을 설명하기 위해 만든 상황입니다. 실제 고객의 후기나 성과 사례는 아닙니다.

## 실제 콘텐츠에 함께 적용해 봐요
