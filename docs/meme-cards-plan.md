# 밈카드 기획안

## 1. 목표와 기본 가정

익숙한 밈을 긁어 공개하고 프로필에 모으는 무료 수집 경험을 만든다. 자체 제작한 포스터 아트와 활용 설명으로 밈을 알아간다. **유명 밈 1,000종**을 목표로 시작했으며, 참조와 중복 검토를 거쳐 기존 공개 밈을 연결한 1,000종 카탈로그를 선정했다. 모든 밈의 세계적 유명도를 측정한 결과는 아니다.

승인된 기본값은 **무료·무제한 수집**이다. 원하는 공개 카드를 선택해 긁고 수령한다. 랜덤 발견은 향후 선택 기능으로 남긴다. 결제·거래·NFT·코인·희소성 등급·당첨 확률은 도입하지 않는다. 소장은 서비스 내 보유이며 원본의 이용 권한을 부여하지 않는다.

승인된 무료 수집 기획에 따라 구현·검증·배포까지 진행한다. 이 문서는 제품 기준이며, ChatGPT 앱 신청·승인 대기는 별도 보류 사안이다.

## 2. 핵심 이용 흐름

**카드 선택 → 봉인 → 긁는 중 → 공개 → 로그인 필요 시 로그인 → 수령 중 → 소장 완료**

| 상태 | 화면과 행동 |
| --- | --- |
| 봉인 | 카드 번호, 테마, 긁기 안내를 보여준다. 손가락·마우스로 긁거나 ‘바로 공개’ 버튼을 누른다. |
| 긁는 중 | 긁힌 부분에서 아트가 드러난다. 초기 제안 30~40% 범위에서 구현 기준은 35%이며 사용성에 따라 조정할 수 있다. |
| 공개 | 밈 이름·아트·활용 문장을 보여준다. ‘내 카드로 수령’과 상세 보기, 다른 카드 찾기를 제공한다. |
| 로그인 | 게스트가 수령을 눌렀을 때 기존 Supabase 로그인을 안내한다. 공개한 카드와 돌아올 위치를 보존한다. |
| 수령 중 | 로그인 후 **같은 카드에서 다시 수령을 눌러야** 저장된다. 진행 상태를 표시하고 중복 클릭을 막는다. |
| 소장 완료 | ‘소장 중’ 배지, 프로필 컬렉션 보기, 다음 카드 찾기를 제공한다. 이미 보유했다면 같은 완료 상태로 안내한다. |

긁기 면적은 연출 기준이며 소유권·보안 증거가 아니다. 선택한 유효 카드를 누구나 공개·수령하도록 설계한다.

로그인 전 소장 표시와 로그인 직후 자동 수령은 하지 않는다. 수령 취소와 다른 카드 선택을 유지한다.

## 3. 화면 구성

`/meme-cards`에는 무료 이용 안내, 컬렉션 링크, 이름 검색·카테고리 필터, 24종씩의 목록을 배치한다. 선택한 카드가 공개 영역에서 열린다. 수령할 때만 로그인한다는 안내를 제공한다.

`/my`의 **‘밈카드’ 탭**에는 보유 종류 수/1,000, 그리드, 이름·카테고리 필터, 최근 수령 순 정렬을 제공한다. 카탈로그의 ‘소장 중’ 배지로 미보유 카드를 구분한다. 중복 수령은 수량을 늘리지 않는다.

컬렉션은 본인만 읽는다. ‘저장한 밈’, 공개 `/collections`, Plus 폴더·메모와 구분한다. 무료 계정도 수집하며, 빈 상태에는 첫 카드 링크를 제공한다.

```text
탐색: [무료 안내 · 내 컬렉션] [검색 · 카테고리] [24종 목록 · 페이지 이동]
공개: [봉인 카드 → 긁기/바로 공개 → 아트·활용] [수령] [상세·출처]
MY:   [프로필] [저장한 밈 | 밈카드] [보유/1,000] [필터·최근순] [소장 그리드]
```

## 4. 카드 디자인과 콘텐츠

세로 포스터 앞면에는 **번호, 이름, 카테고리, 자체 제작 아트, 한 줄 사용 상황**을 배치한다. 뒷면·펼침 영역에는 뜻, 활용 예시, 주의할 맥락, 작은 상세·출처 링크를 둔다.

SVG 도형·타이포그래피·자체 기호로 상황을 표현한다. 구현은 74개 기호, 16개 모티프, 8개 구도를 공유하는 절차적 아트다. 66개 의미 기호 묶음, 153개 모티프·기호·구도 조합과 고유 시드 1,000개를 사용한다. 주요 요소는 해당 밈의 상황을 나타내며, 1,000개의 개별 수작업 일러스트를 뜻하지 않는다. 테마는 가치 등급이 아니다.

제목은 실제 텍스트로 제공한다. 긴 제목·여러 언어의 길이를 고려하며 검수된 번역을 사용한다. 외부 썸네일·사진은 권리 근거가 확인되어야 한다. 출처 링크·공개 승인만으로 재사용 허가를 주장하지 않는다.

## 5. 1,000종 카탈로그 제작 기준

**2026-10-07 초기 조사:** 역사 자료 1,726개 ID 중 현재 일치 1,631개, `approved`·`green`·게시일 존재 조건의 후보는 821개였다. 제목 정규화 후 818종이며 771개에 별칭이 있어 역사 자료만으로는 최소 182종이 부족했다. 전체에서 같은 공개 조건을 충족한 3,423건을 확인했고, 게시일 조건 없는 3,885건과 구분했다. 초기 확장 목록의 약 1,959묶음은 중간 수치다.

**2026-10-07 최종 선정:** 재사용 가능한 참조 연결 후보 묶음 1,305개에서 1,000종을 확정했다. 독립 검토가 제목·설명·별칭 기준과 최종 수정분을 확인했다. 모든 참조 URL을 다시 방문하거나 보편적 유명도·원본 이미지 이용 허가를 검증했다는 뜻은 아니다. 상세 근거는 [카탈로그 문서](meme-card-catalog.md)와 [구현 기록](meme-cards-implementation.md)에 있다.

기존 승인 밈 ID를 참조하고 별칭·동의어·번역·연도 변형을 검토해 **다른 밈 1,000종**을 선정했다. 부족분은 기존 공개 데이터에서 추가 선별했으며 이름·유래를 만들지 않았다. 기존 별칭 중 서로 다른 노래·인물을 가리키는 오류는 카드의 동의어로 그대로 사용하지 않았다.

번호·대표 밈 ID·제목·별칭·카테고리·활용·출처·아트·검수 상태를 기록한다. 기존 검수 상태를 바꾸거나 외부 밈을 `house_original`로 분류하지 않는다. 자체 제작은 **카드 아트**를 뜻한다.

품질 검토 순서는 **대표 샘플 10종 → 파일럿 100종 → 최종 1,000종**으로 잡았다. 최종 카탈로그는 1,000종이며 이후 변경에도 다음 기준을 유지한다.

- 개수와 고유 번호·밈 계보가 일치하고, 별칭·제목·연도 변형으로 수량을 늘리지 않았다.
- 이름·뜻·사용 예시는 확인 가능한 출처에 근거하며 유효한 HTTPS 상세·출처 링크를 가진다.
- 카드별 아트가 구별되고 밈과 연결되며, 필요 시 원본 이미지 사용 근거가 확인되었다.
- 작은 화면에서 제목과 활용 문장을 읽을 수 있고, 대표 아트가 정상 표시된다. 미완성·빈 아트는 공개하지 않는다.
- 최종 카탈로그는 검수된 정확히 1,000종이다. 부족하면 제작 중으로 표시하고 대체 생성으로 채우지 않는다.

## 6. 접근성과 예외 처리

키보드·화면 읽기용 ‘바로 공개’ 버튼과 공개·수령 상태 메시지를 제공한다. 움직임 줄이기에서는 흔들기·입자·전환을 줄인다. 모바일 터치 영역을 확보하고 카드 밖의 스크롤을 유지한다.

화면 닫기·로그인 이동에도 공개 상태와 카드 ID를 보존한다. 같은 탭의 재방문·새로고침에 복원하고, 수령 완료 후 정리한다. 복원 정보가 없으면 새 카드 선택을 안내하며 다른 카드로 바꿔치기하지 않는다.

세션 만료 시 공개한 카드를 유지하고 로그인한다. 저장 실패는 재시도를 제공하며 완료로 표시하지 않는다. 반복·동시 수령은 1종으로 끝난다. 비공개·삭제·검수 보류 카드의 수령은 거절한다. 기존 보유 기록은 유지하되 이름·본문을 ‘내용 확인 중’으로 가린다.

## 7. 구현 경계

공개 카탈로그와 개인 소장 관계를 분리했고, 소장 관계에 `(user_id, card_id)` 고유 키와 본인 읽기 RLS를 뒀다. 수령마다 `getUser()`와 현재 공개 가능 여부를 확인하며 익명 인증 계정은 거절한다. 브라우저의 보유 표시는 소유권 근거가 아니다. 로그아웃·다른 탭 로그인·계정 전환 시 이전 계정의 소장 화면을 비운다.

공개 목록은 제한된 캐시와 페이지 단위 조회를 사용하고, 개인 컬렉션은 사용자별 비공개 응답으로 제공한다. 1,000종 전체를 브라우저에 렌더하지 않는다. 무료 공개·긁기마다 데이터베이스 추첨 행을 만들지 않고 실제 수령에서만 소장 관계를 기록한다. 기존 인증 복귀, 개인정보, 관리자 검수 흐름을 재사용한다.

## 8. 완료 기준과 산출물

10종 샘플과 100종 파일럿은 중간 품질 기준이며 **최종 출시 대상은 선정된 1,000종**이다. 게스트 공개, 동일 카드 로그인 복귀, 명시적 수령, 중복 안전성, 세션 만료·저장 실패 복구가 동작해야 한다. MY 수량·목록은 실제 보유 관계에 맞고 다른 사용자의 컬렉션을 읽을 수 없어야 한다. 모바일·키보드·움직임 줄이기와 숨겨진 카드 처리를 확인한다. 카탈로그·DB 적용 완료와 웹 배포·실제 인증 수령 검증 완료는 별도로 기록한다.

이번 작업 산출물은 10종 디자인 샘플, 100종 파일럿·이용 흐름 검증, 최종 1,000종 카탈로그·아트·중복 및 출처 검수표, 구현·배포와 운영 검증 기록이다. 최종 단계 전에는 ‘1,000종 수집 완료’나 제작 완료를 안내하지 않는다.
