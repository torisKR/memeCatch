# 밈 탐색 UI 축약 — 로컬 변경 계획

## 목적

검색 → 밈 이름·한 줄 뜻 → 영상·사용 맥락을 바로 읽는 화면으로 정리한다.
확인된 외부 확산과 편집 추천·최근 등록·내부 인기는 섞지 않는다.

## 작은 변경 단위

1. 홈: 장식형 스크롤 스토리와 반복 홍보 섹션을 기본 화면에서 빼고 검색·실제 밈 목록을 앞에 둔다.
2. 공통 탐색: 헤더·메뉴·푸터의 보조 기능을 정리하고 모바일에서 겹치지 않게 한다.
3. 카드: 제목과 뜻을 먼저 보여주고 장식 파형·반복 문구·과도한 이미지 높이를 줄인다.
4. 상세: 대표 영상·사용 예·주의 맥락을 먼저, 긴 뜻·유래·자료·댓글은 펼침으로 둔다. 유료·후원 안내를 본문에서 뺀다.
5. 탐색: 검색·필터·실제 결과 외 장식 패널을 없앤다.

## 보존 계약

기존 URL, canonical, 언어 전환, 승인된 미디어 필터와 VideoObject 검증 게이트,
안전 신호, 실제 Life signal, 출처, 조회·반응·저장·공유를 보존한다.
데이터·점수·검수 상태를 변경하지 않고 운영 배포·결제·영상 업로드를 하지 않는다.
기존 미커밋 변경을 보존하며 새 의존성을 추가하지 않는다.

## 검증

변경 전 관련 회귀 테스트 → 변경 후 렌더·상태·접근성 계약 테스트 → lint·typecheck.
실제 로컬 화면의 데스크톱·모바일과 검색·접힘·메뉴를 확인한다.
실데이터 연결이 없으면 빈 상태와 고정 테스트 자료 검증을 구분해 기록한다.

## 롤백

이번 UI 변경의 선택적 역패치만 사용한다. 전체 checkout/reset이나 기존 변경 덮어쓰기는 하지 않는다.
DB·정책·비밀 설정을 바꾸지 않으므로 관련 롤백은 없다.

## 구현 결과

- 홈: `components/home/{home-experience,home-discovery,home-trend-discovery}.tsx`와 두 CSS 모듈, `lib/{home-copy,home-discovery-copy}.ts`.
  검색과 실제 최근 공개 항목만 기본 노출한다. 외부 확산은 기존 승인 요약이 있을 때만 별도로 표시한다.
  이미지가 없는 항목에 커다란 가짜 썸네일을 만들지 않는다.
- 공통 셸: `components/{global-header,header-discovery-links,header-menu,bottom-nav,site-footer}.tsx`.
  모바일 7탭→4탭, 언어·제보·상품·Plus는 보조 메뉴로 이동했다.
- 상세: `app/(default)/memes/[key]/page.tsx`, `app/[locale]/memes/[key]/page.tsx`.
  뜻·상태·미디어를 먼저 배치했다. 긴 설명·유래·자료·반응은 네이티브 펼침으로 보존했다.
  한국어 관련 밈은 4개로 제한하며 상세의 무한 스트림과 본문 홍보를 제거했다.
- 카드·상태: `components/{answer-card,meme-card,meme-thumbnail,save-button,safety-badge,safety-rationale,source-evidence,meme-embed,usage-examples,meme-external-trend-evidence}.tsx`.
  안전 색·아이콘·실제 생애주기를 유지하면서 글로우·파형·중복 문구를 제거했다.
- 탐색: `app/(default)/explore/page.tsx`, `components/explore-filters.tsx`.
  장식 패널을 제거하고 내부 급상승·내부 인기·최근 등록의 이름을 구분했다.
- 기타: `app/_root/root-document.tsx`의 자동 설치·새 소식 팝업 제거,
  `components/meme-chatbot.tsx`의 런처를 작은 정적 아이콘으로 축약,
  `app/(default)/layout.tsx`의 근거 없는 3초·실시간 문구 제거.

데이터 흐름과 API·DB 모델은 기존 경로를 사용한다. 서버 공개 조회 → 기존 검수/미디어 필터 → 축약한 UI이며,
영상 구조화 데이터의 public + public_embed_verified + 유효 메타데이터 게이트는 변경하지 않았다.
기존 조회·저장·공유·반응 API의 동작이나 결제 상품을 변경하지 않았다.

## 검증 기록

- 변경 관련 36개 테스트 파일 335개 통과. 마지막 홈 썸네일 축약 후 홈 테스트와 lint/typecheck를 추가 확인했다.
- 대상 ESLint, TypeScript `--noEmit`, `git diff --check` 통과.
- impeccable 정적 UI 검사 1회: 20개 대상의 기계적 패턴 경고 0건. 디자인 품질 전체 인증을 뜻하지 않는다.
- 브라우저: 1280×720 홈 6개 실제 항목, 가로 넘침 0px.
  375×812 홈·상세, 320×568 탐색과 필터 펼침/접힘에서도 가로 넘침 0px.
  상세 상단 높이 데스크톱 약 155px, 모바일 약 171px.
- 메뉴 Escape 후 닫힘·포커스 복귀, Enter로 뜻·유래 펼침을 확인했다.
- 모션 감소는 기존 관련 컴포넌트 테스트와 정적 구조로 확인했다. OS 설정을 변경한 실기 검증은 하지 않았다.
- 로컬 확인 URL: `http://127.0.0.1:3020/`. 전용 `.local/ui-readonly-runtime-20261018.mjs`가
  운영 읽기만 허용하고 외부 쓰기·분석 이벤트 기록을 차단한다. 환경 파일은 변경하지 않았다.

## 검증 한계·남은 콘텐츠 문제

- 전체 운영 빌드·운영 배포·Google 리치 결과 재검증·영상 업로드는 수행하지 않았다.
- 초기 로컬 연결의 키 누락·미디어 원장 읽기 실패로 일부 영상/이미지는 출처 링크 또는 텍스트로 대체되었다.
  이 화면 확인은 실제 임베드 재생 성공의 증거가 아니다. 검증 게이트를 완화하지 않았다.
- 콘솔에는 쓰기 차단에 따른 분석/조회 기록 실패, 미디어 원장 경고,
  개발 서버 재시작/HMR 도중 오래된 CSS 청크 연결 오류가 기록되었다.
  따라서 무오류 콘솔 또는 운영 네트워크 검증 완료로 보고하지 않는다.
- 탐색 중 `u5gw45cb-bedrock-canary-mth9nf8a` 등 테스트성 공개 콘텐츠를 확인했다.
  해당 자료의 검수·비공개 전환은 별도 운영 콘텐츠 변경이며, 이번 UI 작업에서 DB를 일괄 수정하지 않았다.
- 일부 ExploreGrid 테스트는 API 키가 없는 테스트 환경의 결과 수 조회 경고를 출력하지만 테스트는 통과했다.
