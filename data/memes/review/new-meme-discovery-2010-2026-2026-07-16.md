# New meme discovery — challenges & trends (2026-07-16)

Review-only **new** Korean meme titles for 2010–2026 that are **not** already in
`data/memes/verified` or `data/memes/raw` (deduped with `memeTitleKey` on title +
aliases). Nothing here is published automatically.

## Why

Previous social crawls only searched sources for **existing catalog** titles.
Users also treat challenges and period trends as memes; those need a separate
discovery pass with strict de-duplication.

## Dedup rules

1. Build key set from all verified + raw `title` and `aliases` via `memeTitleKey`
2. Skip any discovered title whose key collides
3. Within the discovery batch, keep the first occurrence only
4. Korea timeline only (overseas namu section excluded)
