# 밈캐치 상품 편집숍·자동 캐러셀 디자인 설계

## 1. 목적

`/products`를 일반 쇼핑몰 목록이 아니라 밈캐치의 정체성이 보이는 **밈 스티커 편집숍**으로 재구성한다. 사용자는 자동 동기화된 애드픽 상품과 밈캐치가 직접 고른 제휴 상품을 명확히 구분하면서, 모바일·태블릿·데스크톱과 한국어·영어·일본어·중국어 환경에서 가로 넘침 없이 상품을 탐색하고 구매 페이지로 이동할 수 있어야 한다.

핵심 목표는 다음과 같다.

- “밈 상품”이라는 성격을 첫 화면과 카드에서 즉시 인지하게 한다.
- 자동 동기화 광고와 편집자 추천을 투명하게 구분한다.
- 수동 가로 스크롤 대신 오른쪽으로 흐르는 자동 캐러셀을 제공한다.
- 자동 재생 중에도 키보드·스크린 리더·모션 민감 사용자가 제어권을 가진다.
- 네 언어에서 번역 누락, 일본어 줄바꿈 실패, 헤더 언어 선택기 잘림을 제거한다.
- shadcn/ui를 선택적으로 도입하되 밈캐치 고유의 편집숍 미감을 유지한다.

## 2. 범위

### 포함

- `/products` 히어로, 광고 고지, 상품 섹션과 카드의 시각 계층 재설계
- 애드픽 자동 상품을 위한 우측 자동 이동 캐러셀
- 밈캐치 에디터 픽과 실시간 광고 상품의 명확한 라벨링
- 모바일·태블릿·데스크톱 반응형 레이아웃
- 한국어·영어·일본어·중국어 UI 전체 번역과 언어별 줄바꿈
- 헤더 언어 선택기의 모바일 표현 개선
- 캐러셀 재생/일시정지, 이전/다음 버튼, 키보드와 스크린 리더 지원
- 로딩·빈 상태·갱신 지연 상태의 일관된 표현
- 컴포넌트·다국어·반응형 회귀 테스트와 실제 브라우저 검증

### 제외

- 애드픽 API·Supabase 동기화 데이터 모델 변경
- 결제·주문·재고 처리
- 판매량이나 구매 전환을 근거 없이 추정하는 표현
- 상품 원문 이름의 기계 번역
- 홈 또는 다른 콘텐츠 페이지의 전면 재설계
- 새 제휴사 연동

## 3. 디자인 방향

### 콘셉트

디자인 방향은 **밈 스티커 편집숍**이다. 상품 카드를 단순한 커머스 타일이 아니라 인터넷 문화에서 발견한 물건을 큐레이션한 스티커 보드처럼 보이게 한다. 히어로에는 `밈캐치 편집숍`과 `요즘 인터넷에서 자주 보이는 상품들`에 해당하는 로케일별 카피를 배치한다.

### 팔레트

- Flame `#FF5C38` — 핵심 강조, 활성 상태, 대표 CTA
- Ink `#16161A` — 제목과 본문, 대비가 필요한 CTA
- Cream `#FAF6F0` — 편집숍 배경
- Surface `#FFFFFF` — 카드 표면
- Trust Yellow `#FDF3D8` — 광고 고지와 정보성 안내

작은 본문과 버튼은 WCAG AA 대비를 우선한다. 밝은 Flame 배경 위 작은 흰색 텍스트는 사용하지 않고, 필요하면 Ink 텍스트 또는 더 어두운 상호작용 색을 사용한다.

### 타이포그래피

- 제목: Pretendard 계열의 굵은 무게로 짧고 강한 편집숍 인상
- 본문: 동일 계열의 regular/medium으로 가독성 유지
- 가격·갱신 시각: 고정폭 계열로 데이터 성격 강조

### 시그니처 요소와 미적 위험

상품 카드의 한 모서리에 살짝 회전한 스티커형 라벨과 굵은 외곽선을 사용한다. 이는 일반적인 둥근 SaaS 카드에서 벗어나는 의도적인 미적 위험이다. 다만 회전은 1–2도 이내로 제한하고 콘텐츠 컨테이너에는 적용하지 않아 줄바꿈, 포커스 링, 모바일 정렬을 해치지 않는다.

## 4. 정보 구조

페이지 순서는 다음과 같다.

1. 편집숍 히어로 — 페이지 성격과 가치 제안
2. 투명한 광고 고지 — 제휴 링크와 가격 변동 가능성
3. 실시간 광고 상품 — 애드픽 동기화 상품 자동 캐러셀
4. 밈캐치 에디터 픽 — 기존 수동 제휴 상품의 안정적인 그리드
5. 갱신·가격 안내 — 마지막 동기화와 판매처 확인 안내

자동 동기화 상품은 `실시간 광고 상품`, 수동 구성 상품은 `밈캐치 에디터 픽`으로 표시한다. 모든 카드에는 별도로 `광고·제휴` 의미의 배지를 유지해 섹션 제목만으로 광고 관계를 추측하게 하지 않는다.

기존 `밈캐치 인기`는 최근 7일 내부 클릭 수가 있는 경우에만 표시하고, 설명에 판매량이 아니라 밈캐치 내 클릭 기반임을 명시한다. `베스트셀러`, `품절 임박`, `구매 폭주`, 가짜 카운트다운은 사용하지 않는다.

## 5. shadcn/ui 구성

shadcn/ui는 전체 디자인을 결정하는 템플릿이 아니라 접근성과 상호작용 기반으로 사용한다.

- `Card` — 상품 카드와 정보 블록
- `Badge` — 광고, 실시간, 에디터 픽 라벨
- `Button` — CTA와 캐러셀 제어
- `Carousel` — Embla 기반 캐러셀 구조와 키보드 제어
- `Alert` — 제휴·가격 고지
- `Skeleton` — 데이터 로딩 자리표시자

프로젝트에 기존 shadcn 설정이 없으므로 필요한 최소 의존성과 유틸리티만 추가한다. 색상·모서리·그림자·간격은 기본 예제를 그대로 복사하지 않고 위 디자인 토큰에 맞춘다.

## 6. 자동 캐러셀 동작

### 기본 동작

- 상품 트랙은 화면 기준 **오른쪽 방향**으로 일정하게 이동한다.
- 마지막 카드 뒤에 첫 카드가 자연스럽게 이어지는 무한 루프를 사용한다.
- 이동 속도는 내용을 읽을 수 있을 정도로 느리고 일정하게 유지한다.
- 카드 수가 한 화면을 충분히 채우지 못하면 자동 재생을 비활성화하고 정적 배치한다.

### 사용자 제어

- 마우스 hover 또는 키보드 focus가 캐러셀 안에 있으면 자동 재생을 일시정지한다.
- 이전, 다음, 재생/일시정지 버튼을 항상 제공한다.
- 사용자가 직접 이동한 뒤에는 즉시 다시 끌려가지 않도록 짧은 유예 시간을 둔다.
- 현재 상태는 아이콘뿐 아니라 로케일별 접근 가능한 이름으로 제공한다.
- 포커스 순서는 섹션 제목, 제어 버튼, 상품 CTA 순으로 예측 가능하게 유지한다.

### 모션 접근성

`prefers-reduced-motion: reduce`에서는 자동 재생과 장식성 이동을 시작하지 않는다. 사용자는 이전/다음 버튼과 스와이프로 탐색할 수 있다. 브라우저 탭이 숨겨진 동안에도 재생을 멈춰 불필요한 작업을 방지한다.

## 7. 반응형 레이아웃

### 모바일: 320–639px

- 히어로와 고지는 한 열로 배치한다.
- 캐러셀은 한 카드와 다음 카드의 일부가 보이도록 해 이동 가능성을 전달한다.
- 카드 최소 너비나 긴 텍스트 때문에 페이지 전체가 가로 스크롤되지 않게 한다.
- 언어 선택기는 아이콘만 잘린 형태가 아니라 현재 언어 코드 또는 짧은 이름이 완전히 보이는 버튼으로 표시한다.
- 모든 탭·버튼은 최소 44px 터치 영역을 확보한다.

### 태블릿: 640–1023px

- 캐러셀에 약 두 장의 카드가 보인다.
- 에디터 픽 그리드는 두 열을 기본으로 한다.
- 히어로 카피와 안내의 줄 길이를 제한한다.

### 데스크톱: 1024px 이상

- 캐러셀에 세 장을 기본으로 노출하되 컨테이너 폭에 따라 여백을 유지한다.
- 에디터 픽은 세 열을 기본으로 한다.
- 최대 콘텐츠 폭 안에서 카드 크기와 가격 정보의 시각적 리듬을 맞춘다.

## 8. 다국어와 줄바꿈

지원 로케일은 `ko`, `en`, `ja`, `zh-Hans`다. 다음 항목을 모두 번역 키로 제공한다.

- 히어로 제목·설명
- 실시간 광고 상품·에디터 픽 섹션 제목과 설명
- 광고·제휴, 갱신, 가격 변동 고지
- 상품 CTA
- 이전, 다음, 재생, 일시정지와 캐러셀 접근성 이름
- 로딩, 빈 상태, 오류·갱신 지연 상태

상품명과 판매처명은 외부 원문을 유지한다. CTA의 접근 가능한 이름에는 상품명을 포함해 반복되는 `상품 보러 가기` 링크를 구분한다.

전역 `word-break: keep-all`은 한국어에만 제한한다. 일본어와 중국어는 자연스러운 문자 단위 줄바꿈을 허용하고, 긴 URL성 문자열이나 외부 상품명은 `overflow-wrap: anywhere`에 해당하는 방어 규칙을 적용한다. `<html lang>`은 선택 로케일과 일치해야 한다.

## 9. 상품 카드

각 카드에는 다음을 표시한다.

- 고정 종횡비의 상품 이미지와 로드 실패 대체 표현
- 판매처명
- 최대 줄 수를 통제한 상품명
- 유효한 경우 정상가, 판매가, 계산 가능한 할인율
- `광고·제휴` 배지와 `실시간` 또는 `에디터 픽` 출처 라벨
- 상품명까지 포함한 접근 가능한 CTA
- 가격과 재고가 판매처에서 달라질 수 있다는 가까운 보조 문구

카드 높이는 한 뷰포트 구간에서 안정적으로 맞춰 자동 이동 중 수직 흔들림이 없게 한다. 이미지는 lazy loading과 실패 처리를 유지하고, 가격이 없으면 판매처 확인 문구를 표시한다.

## 10. 상태 처리

- 로딩: 카드 크기를 보존하는 `Skeleton`
- 빈 목록: 캐러셀 제어를 숨기고 준비 중 안내 표시
- 48시간 이상 갱신 지연: 가격이 달라질 수 있다는 `Alert`
- 일부 이미지 실패: 레이아웃을 유지하는 브랜드 자리표시자
- JavaScript 실패: 서버 렌더링된 상품 목록과 구매 링크는 계속 접근 가능하도록 점진적 향상을 우선한다.

## 11. 접근성과 성능

- 텍스트·버튼 대비는 WCAG AA를 만족한다.
- 포커스 링은 카드 외곽과 겹쳐도 잘리지 않아야 한다.
- 캐러셀은 영역 이름을 가진 landmark로 제공하고 상태 변화를 과도하게 live announce하지 않는다.
- 장식 라벨은 스크린 리더에서 중복 읽히지 않게 한다.
- 자동 재생 코드는 클라이언트 경계 안으로 제한하고 나머지 페이지는 서버 컴포넌트로 유지한다.
- 이미지 크기와 종횡비를 예약해 CLS를 줄인다.
- 중복 카드가 무한 루프를 위해 렌더링되더라도 스크린 리더와 탭 순서에 중복 노출되지 않게 캐러셀 라이브러리의 접근성 동작을 검증한다.

## 12. 테스트와 완료 기준

### 자동 테스트

- 네 로케일의 새 번역 키 존재와 fallback 부재
- 캐러셀 자동 이동, 일시정지, 이전/다음 동작
- reduced-motion에서 자동 재생 비활성화
- 빈 상품 목록과 부족한 카드 수에서 정적 처리
- CTA 접근성 이름에 상품명 포함
- 실시간 광고 상품과 에디터 픽 라벨 구분

### 브라우저 검증

인앱 브라우저에서 최소 다음 조합을 확인한다.

- 폭 320, 375, 768, 1280px
- 한국어, 영어, 일본어, 중국어
- 페이지 전체 `scrollWidth === clientWidth`
- 일본어 고지·상품명이 카드 밖으로 넘치지 않음
- 모바일 언어 선택기의 텍스트와 터치 영역이 온전히 표시됨
- 캐러셀이 오른쪽으로 이동하고 hover/focus/reduced-motion에서 멈춤
- 버튼 키보드 조작, 포커스 표시, 접근 가능한 이름
- 이미지 실패와 갱신 지연 상태에서 레이아웃 유지

### 완료 기준

- 모든 자동 테스트, lint, 타입 검사와 production build가 통과한다.
- 네 로케일·네 대표 폭에서 페이지 가로 넘침이 없다.
- 광고와 편집자 추천이 시각적·문구적으로 구분된다.
- 자동 캐러셀은 사용자 제어와 reduced-motion을 존중한다.
- 사용자 소유의 기존 `.gitignore`, `.pnpm-store` 변경은 수정하거나 커밋하지 않는다.
