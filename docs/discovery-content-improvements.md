## 구현 내용

### 홈에서 전체 검색으로 이동

- 홈의 최근 밈 6개 목록 안에서 찾는 필터와 전체 카탈로그 검색을 구분한다.
- 전체 검색은 GET 폼으로 검색어를 URL에 전달하고, 전체 탐색으로 이동하는 CTA를 제공한다.
- 검색 폼과 CTA 문구를 기존 5개 locale에 반영한다.
- 사용 가능한 대표 썸네일이 있으면 카드에서 보여 주고, 없으면 기존 추상 이미지 fallback을 사용한다.
- 관찰한 최신 밈 6개에는 썸네일 메타데이터가 없었다. 이미지 표시 지원이 기존 데이터에 썸네일을 새로 생성했다는 뜻은 아니다.

### 검색어와 이동 상태 유지

- SearchInput이 서버 컴포넌트의 검색 결과 갱신과 뒤로가기·앞으로가기 상태를 반영하도록 수정한다.
- 이전 요청의 늦은 응답이 현재 입력을 덮어쓰는 상황을 방지한다.
- 탐색 결과가 없을 때 제보로 전달하는 `name`을 보존한다.
- 로그인이 필요한 제보 경로에서도 allowlist에 포함된 `name`만 최대 100자로 유지한다. 임의 리다이렉트 대상이나 다른 쿼리 매개변수의 허용 범위를 넓히지 않는다.

### 등록 전 검증과 읽기 전용 품질 검사

- 기존 순수 함수 `memeTitleKey`를 재사용해 NFKC·공백·문장부호·기호 정규화 기준을 통일한다.
- 제목과 요약이 정규화 후 같으면 새 카탈로그 등록을 차단하고, 뜻이나 사용 상황을 설명한 요약을 요청한다.
- 제목을 포함하더라도 설명이 추가된 요약은 허용한다.
- 품질 검사에서 같은 정규화 제목 및 다른 문서 제목과 충돌하는 별칭을 찾는다.
- 정규화 키가 빈 문자열인 기호만 제목·별칭은 중복 인덱스에서 제외한다. 서로 다른 별 이모지를 같은 제목으로 오탐하지 않는다.
- `publicSourceUrl`로 공개 출처 URL 정책을 재사용한다. 무효 URL을 유효한 근거 수에 포함하지 않고 별도 검수 항목으로 표시한다.
- 기존 공개 출처의 HTTP·HTTPS 정책을 유지한다. 새 카탈로그 등록의 HTTPS 요구도 유지한다.
- URL 검사는 문법·호스트 정책 검사이며 링크 생존, DNS 목적지, 사실성 또는 이용 권한을 인증하지 않는다.
- 재생용 `meme_contents` 링크와 근거용 `meme_sources`를 구분한다. 대표 영상이 있다는 이유로 근거가 있는 문서로 집계하지 않는다.

### 관리자 제보 승인과 저장 실패 처리

## 운영 반영과 남은 작업

사용자 요청에 따라 한글 커밋 후 main에 반영하고 기존 Vercel Git 배포를 진행했다. 운영 소스 `a316602`는 Vercel 배포 `dpl_5kC5DDBLF19RzoNX2uoc9rvwnUz2`에서 READY를 확인했고 catchmeme.com의 연결과 기존 9개 cron 정의를 확인했다. 같은 소스의 첫 빌드는 외부 임베딩 모델 다운로드 HTTP 503으로 실패했으며, 동일 커밋 재배포 1회로 복구했다.

최종 실제 운영 브라우저 요청은 HTTP 200, `retrieved` / `hybrid`, TMI 근거 카드 1건이었다. 모바일·데스크톱·320×568·다크 화면, Escape·포커스 복귀, 로그인 화면 숨김을 통과했고 페이지 오류와 수평 넘침은 0이었다. 초기 운영 QA에서는 무료 모델의 `generated`도 확인했지만, 최신 요청에서 생성 성공이나 안정적인 무료 모델 가용성을 확인한 것은 아니다. Vercel 경고 로그 조회는 성공했으나 해당 생성 진단 행이 없어 마지막 생성 불채택 원인은 확정하지 않았다. 로컬 opencodex 생성 성공과 운영 무료 생성의 가용성을 구분한다.

여러 운영자의 동시 제보 승인은 별도의 데이터베이스 원자성 설계가 필요하다. 출처 없는 문서와 중복 후보는 기존 수동 검수 경로에서 근거를 확인한 뒤 처리한다. 연도·사실·권리 정보를 추정해서 채우지 않았다.
