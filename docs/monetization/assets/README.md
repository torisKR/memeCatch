# MemeCatch Plus 마케팅 이미지

Latpeed 멤버십 상품 대표이미지 등에 쓰는 브랜드 이미지. HTML을 브라우저로
렌더해 PNG로 뽑는다(브랜드 토큰: accent #ff5c38, flame-400 #ff7d54, ink #16161a).

| 소스(HTML) | 렌더 규격 | 용도 |
| --- | --- | --- |
| card.html | 400×200 (2x 800×400) | 기본 대표이미지(다크) |
| card-light.html | 400×200 (2x 800×400) | 밝은 배경 버전 |
| card-square.html | 800×800 | 정사각형(앱 아이콘·소셜 프로필) |
| card-price.html | 400×200 (2x 800×400) | 월 3,900원 가격 배지 |

재생성: 뷰포트를 해당 규격으로 두고 파일을 열어 스크린샷. 2x는 `document.body.style.zoom='2'`.
